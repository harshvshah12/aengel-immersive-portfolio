# AENGEL — Immersive Portfolio Recreation

A Next.js + TypeScript recreation project inspired by the structure and interaction language of [aengel.io](https://aengel.io/) and the visual/animation reference on [Landing Love](https://www.landing.love/sites/aengel/).

## Run locally

```bash
npm install
npm run dev
```

## Current implementation

- Dark technical editorial layout, navigation and responsive sections
- Interactive Three.js / React Three Fiber hero scene with procedural wire geometry
- Entrance interaction and scroll-triggered GSAP manifesto reveals
- Six-project carousel with previous/next and touch-swipe controls
- About and contact sections

## Important

This is an independent recreation, not the original source code or a transfer of proprietary assets. The first pass uses procedural 3D geometry and authored styling. The next implementation pass should replace approximations with verified, properly licensed media/assets where available, and refine the hero scene and project-specific transitions against the reference recording.

## Stack

Next.js 15, React 19, TypeScript, Three.js, React Three Fiber, Drei, GSAP ScrollTrigger.
